## Building your own integrations

You can build your own integrations with CodeQR's infrastructure for both **links** and **QR Codes** using our [API](/api-reference/introduction).

1. Read the documentation on how to [create links](/api-reference/endpoint/create-a-link) or [create QR Codes](/api-reference/endpoint/create-a-qrcode).
2. Learn how to [integrate CodeQR into your application](/integrations/quickstart).
3. [Reach out to us](https://codeqr.io/contact/support) to feature your integration in the integrations marketplace.

## Integration webhooks

CodeQR also supports webhooks for integrations. You can use these webhooks to track events for both links and QR Codes. Learn more in the [webhooks](/concepts/webhooks/introduction) documentation.

Here's a list of the webhooks that CodeQR supports:

- [`link.created`](/concepts/webhooks/event-types#link-created) – when a new link is created
- [`link.updated`](/concepts/webhooks/event-types#link-updated) – when a link is updated
- [`link.deleted`](/concepts/webhooks/event-types#link-deleted) – when a link is deleted
- [`link.clicked`](/concepts/webhooks/event-types#link-clicked) – when a link is clicked
- [`qrcode.created`](/concepts/webhooks/event-types#qrcode-created) – when a new QR Code is created
- [`qrcode.updated`](/concepts/webhooks/event-types#qrcode-updated) – when a QR Code is updated
- [`qrcode.deleted`](/concepts/webhooks/event-types#qrcode-deleted) – when a QR Code is deleted
- [`qrcode.scanned`](/concepts/webhooks/event-types#qrcode-scanned) – when a QR Code is scanned
- [`page.created`](/concepts/webhooks/event-types#page-created) – when a new page is created
- [`page.updated`](/concepts/webhooks/event-types#page-updated) – when a page is updated
- [`page.deleted`](/concepts/webhooks/event-types#page-deleted) – when a page is deleted
- [`page.visited`](/concepts/webhooks/event-types#page-visited) – when a page is visited
- [`lead.created`](/concepts/webhooks/event-types#lead-created) – when a new lead is created
- [`sale.created`](/concepts/webhooks/event-types#sale-created) – when a new sale is created
